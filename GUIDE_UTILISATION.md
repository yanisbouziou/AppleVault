## Première ouverture et profils

À la première ouverture, crée un profil avec ton nom complet et ton pseudo. Le mot de passe est facultatif. Active **Exiger le mot de passe à l’ouverture** si AppleVault doit demander ce mot de passe au lancement.

Chaque profil a sa propre collection. Pour changer de profil lorsque l’app est ouverte, va dans **Réglages > Profils** et clique sur le profil voulu. Sur l’écran de verrouillage, tu peux aussi sélectionner un profil dans le menu avant de saisir son mot de passe.

Pour modifier le nom, le pseudo ou le mot de passe, ouvre **Profil local** ou **Mon profil…**. Pour créer un autre profil, ouvre **Réglages > Profils > Ajouter un profil…**. Pour en supprimer un, clique sur la corbeille à côté du profil dans **Réglages > Profils**, puis confirme. Cela efface définitivement sa collection, ses sauvegardes, ses photos et ses documents. La suppression du dernier profil ramène à l’écran de création.

Pour verrouiller manuellement l’app, ouvre le menu **Sauvegarde** de la barre d’outils et choisis **Verrouiller AppleVault**.

## Ajouter et gérer les appareils

### Ajouter une fiche

1. Clique sur **Ajouter un appareil** (bouton `+` dans la barre d’outils).
2. Pour remplir les informations d’identification, choisis un modèle dans **Choisir dans le catalogue Apple**, ou saisis un numéro A ou une référence commerciale puis clique **Rechercher**. La recherche consulte le catalogue intégré et les fiches de la collection.
3. Complète les champs utiles et clique **Enregistrer**. Le modèle est obligatoire ; les autres champs peuvent être ajoutés plus tard.

La fiche peut contenir le modèle, l’identifiant technique (par exemple `iPhone6,1`), le numéro A, la référence commerciale (par exemple `M21HFZU/A`), le stockage, la couleur, le numéro de série, la version iOS/iPadOS, l’année de sortie et l’état. Le catalogue peut afficher une image et un lien **Fiche technique Apple** quand ces informations sont disponibles.

Tu peux également renseigner la batterie, l’achat, le vendeur, une valeur personnalisée ou laisser l’estimation automatique, ainsi qu’une fourchette de valeur. Ajoute les réparations, rappels d’entretien, fin de garantie, accessoires, boîte, chargeur, facture, informations de prêt, notes, étiquettes, jailbreak et blobs SHSH au besoin. La photo personnelle se choisit dans **Photo personnelle**.

### Modifier ou supprimer une fiche

Sélectionne un appareil dans la barre latérale pour ouvrir sa fiche, puis clique **Modifier**. Ajoute une réparation dans **Réparations > Ajouter à l’historique** : tu peux indiquer la date, la description, les pièces, le réparateur et le coût. Clique **Enregistrer** pour conserver les changements.

Dans la fiche détaillée :

- **Ignorer** masque les avertissements de cette fiche dans les pages d’alertes et de fiches à compléter. Le bouton **Réactiver** les remet.
- **Ajouter un document…** joint une facture ou un autre fichier ; clique ensuite son nom pour l’ouvrir.
- **Afficher les notes privées** demande le mot de passe du profil si la protection est activée.
- **Imprimer la fiche…** ouvre la fiche imprimable. Le code QR affiché ne contient que le modèle et l’identifiant, jamais le numéro de série.
- Le bouton en forme de cœur ajoute ou retire l’appareil des favoris.

Pour supprimer un appareil, fais un clic droit sur sa ligne dans la barre latérale, puis choisis **Supprimer**.

## Trouver et organiser sa collection

- Utilise le champ **Rechercher dans la collection** pour trouver un modèle, identifiant, numéro A, référence commerciale, version, numéro de série ou étiquette.
- Ouvre **Filtres** pour filtrer par famille, état ou étiquette et choisir le tri : nom, année, état, valeur, stockage, batterie, version iOS/iPadOS, favoris ou date d’ajout.
- Dans **Filtres**, choisis **Enregistrer les filtres actuels…** pour mémoriser une combinaison. Les filtres enregistrés apparaissent ensuite dans le même menu.
- Clique un appareil dans n’importe quelle liste pour ouvrir sa fiche.

La page **Accueil** montre les cartes d’aperçu, les nouveautés, la date et l’heure, ainsi que la météo de la ville configurée. Le bouton **Fonctionnalités** de la barre latérale décrit les outils disponibles. **Tableau de bord** affiche les statistiques de la collection : nombre d’appareils, dépenses connues, valeur estimée, réparations et état des batteries, entre autres.

Depuis le menu **Sauvegarde** de la barre d’outils, tu peux ouvrir **Mode inventaire…** pour vérifier la présence physique et l’état des appareils, ou **Afficher la collection en plein écran** pour parcourir les fiches dans une galerie. Le mode plein écran propose une recherche et un filtre par famille.

## Utiliser les pages de la barre latérale

- **Entretiens & alertes** regroupe les entretiens proches ou en retard, batteries sous le seuil configuré, garanties à surveiller et retours de prêt prévus.
- **Fiches à compléter** liste les fiches auxquelles il manque un des champs définis comme requis.
- **Mes favoris** rassemble les appareils marqués avec le cœur.
- **Réparations à prévoir** affiche les fiches dont le champ de réparations à prévoir n’est pas vide.
- **Comparer deux appareils** permet de sélectionner deux fiches pour comparer leurs informations côte à côte. Il faut au moins deux appareils.
- **Doublons possibles** repère les fiches qui ont le même numéro de série. Vérifie les fiches avant d’en supprimer une.
- **Liste de souhaits** conserve des modèles à rechercher, avec budget, priorité, notes, lien, prix repéré et date de suivi facultative.
- **Champs requis des fiches** permet de choisir les champs utilisés pour repérer les fiches incomplètes.
- **Appareils prêtés** liste les fiches avec un emprunteur renseigné et leur date de retour prévue.
- **Historique d’activité** montre les ajouts et modifications enregistrés pour le profil actuel.

Dans **Sauvegarde > Scanner un code depuis une image…**, sélectionne une image contenant un code-barres. AppleVault lit le code et cherche une fiche correspondante dans la collection ; le scan ne crée pas de fiche.

## Sauvegarder, importer et exporter

Les changements sont enregistrés localement si **Réglages > Données > Enregistrer la collection sur ce Mac** est activé. Pour des instructions complètes de sauvegarde avant une mise à jour et de restauration, consulte la section correspondante du [README](README.md#sauvegarder-la-collection-avant-une-mise-à-jour).

Dans le menu **Sauvegarde** de la barre d’outils :

- **Créer une sauvegarde JSON…** enregistre une copie complète des fiches de l’appareil ; choisis l’emplacement dans la fenêtre de partage.
- **Restaurer depuis un fichier JSON…** importe des fiches. Les fiches avec le même identifiant sont remplacées ; les autres sont ajoutées. Vérifie d’abord le profil actif.
- **Exporter en CSV…** crée un tableau ouvrable dans Numbers ou Excel.
- **Exporter en PDF…** crée une version imprimable de la collection.
- **Importer une collection CSV…** affiche un aperçu avant l’import. Tu peux ignorer les numéros de série déjà présents ; les lignes sans numéro de série restent importables.

Dans **Réglages > Données**, tu peux activer/désactiver l’enregistrement local et les sauvegardes automatiques, choisir leur fréquence et le nombre de copies conservées, ouvrir le dossier de sauvegardes et restaurer une copie automatique. Une restauration depuis cette liste remplace la collection actuelle du profil actif et crée une sauvegarde préalable.

Les photos et documents sont des fichiers séparés du JSON. Ils restent associés si les données locales de l’app ne sont pas supprimées.

## Réglages

- **Apparence** : suivre le thème macOS, clair ou sombre.
- **Langue** : français est actuellement la seule option.
- **Accueil** : définir la ville, la source météo et l’ordre/visibilité des cartes.
- **Alertes** : activer séparément les alertes de batterie sous 80 %, de garantie et de fiches incomplètes. Les avertissements ignorés sur une fiche restent masqués.
- **Confidentialité et exports** : masquer les numéros de série dans l’app et les exports, puis choisir les champs inclus dans les exports PDF/CSV. Les sauvegardes JSON conservent les champs complets.
- **Mises à jour** : rechercher une version sur GitHub manuellement ou activer la vérification au démarrage. AppleVault affiche un lien de téléchargement ; l’installation reste manuelle.
- **Sources météo** : consulter la provenance des données et la licence Open-Meteo.
- **Informations système** : consulter la version de macOS, l’architecture, le nombre de cœurs et la mémoire.
- **Réinitialiser AppleVault…** supprime tous les profils et les données locales. Cette action est définitive ; crée une sauvegarde avant si nécessaire.

## Mettre à jour AppleVault

La page [GitHub Releases](https://github.com/yanisbouziou/AppleVault/releases/latest) propose le ZIP de la dernière version. Télécharge-le, décompresse-le et remplace AppleVault.app dans **Applications**. Les données de collection étant enregistrées séparément, elles devraient rester en place. Pour garder une copie, crée une sauvegarde JSON avant de remplacer l’application.

Les versions disponibles actuellement ne possèdent pas de certificat Developer ID ni de notarisation Apple. Si macOS bloque l’ouverture, fais un Ctrl-clic sur AppleVault.app, choisis **Ouvrir**, puis confirme.

## Menu développeur

Le code `3343` fonctionne uniquement dans une compilation **Debug** lancée depuis Xcode ; il n’est pas inclus dans la version publique.

1. Ouvre `AppleVault.xcodeproj` dans Xcode, sélectionne le schéma **AppleVault** et lance l’app avec **▶︎** ou `⌘R` (configuration Run par défaut : Debug).
2. Dans AppleVault, ouvre **Sauvegarde** dans la barre d’outils et choisis **Verrouiller AppleVault**.
3. Sur l’écran de verrouillage, saisis `3343` dans le champ du mot de passe et clique **Déverrouiller**.
4. Pour sortir, clique **Quitter et reverrouiller** dans le menu développeur.

Le menu fournit des diagnostics et des outils de maintenance. Le code développeur n’ouvre pas la collection à la place du mot de passe du profil.
